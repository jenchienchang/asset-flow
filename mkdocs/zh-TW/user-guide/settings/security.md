# 安全性

AssetFlow 提供選擇性的應用程式鎖定功能，在你完成驗證前遮蔽主視窗與設定視窗。應用程式鎖定不會加密已儲存的紀錄或匯出的備份。

## 啟用應用程式鎖定

1. 開啟**設定**（++cmd+comma++），前往**安全性**區段。
1. 開啟**需要驗證**。

![安全性設定](../../assets/images/settings-security.png)

## 驗證方式

AssetFlow 使用 macOS 的[裝置擁有者驗證政策](https://developer.apple.com/documentation/localauthentication/lapolicy/deviceownerauthentication)進行驗證。依 Mac 與系統設定而定，系統可能提供 Touch ID、附近已配對的 Apple Watch，或 Mac 登入密碼。可用方式及其順序由 macOS 決定；如果驗證失敗或取消，應用程式會保持鎖定。

## 逾時設定

透過兩個獨立的逾時設定控制 AssetFlow 何時自動鎖定：

### 切換應用程式時

切換到其他應用程式後（例如按 ++cmd+tab++），多快自動鎖定。

| 選項        | 行為                        |
| ----------- | --------------------------- |
| **立即**    | 離開 AssetFlow 的瞬間就鎖定 |
| **1 分鐘**  | 離開 1 分鐘後鎖定           |
| **5 分鐘**  | 離開 5 分鐘後鎖定           |
| **15 分鐘** | 離開 15 分鐘後鎖定          |
| **永不**    | 不因切換應用程式而鎖定      |

### 螢幕鎖定或睡眠時

Mac 螢幕鎖定或進入睡眠後，多快自動鎖定。

| 選項        | 行為                         |
| ----------- | ---------------------------- |
| **立即**    | 螢幕鎖定或睡眠的瞬間就鎖定   |
| **1 分鐘**  | 螢幕鎖定或睡眠 1 分鐘後鎖定  |
| **5 分鐘**  | 螢幕鎖定或睡眠 5 分鐘後鎖定  |
| **15 分鐘** | 螢幕鎖定或睡眠 15 分鐘後鎖定 |
| **永不**    | 不因螢幕鎖定或睡眠而鎖定     |

將兩個逾時設定都設為**永不**，會關閉「需要驗證」並解鎖應用程式。再次啟用時，兩個逾時設定都會重設為**立即**。

!!! tip

    如果你經常在 AssetFlow 和試算表之間切換更新數值，可以將「切換應用程式時」設為「永不」。

## 鎖定畫面

鎖定時，遮罩會覆蓋主視窗與設定視窗。若要解鎖：

1. 在鎖定畫面上點選**解鎖**。
1. 使用 macOS 提供的方式完成驗證。

應用程式變為使用中狀態時，可能會自動開啟驗證提示。如果你取消驗證或驗證失敗，可以按**解鎖**再試一次。

![鎖定畫面](../../assets/images/lock-screen.png)

!!! note

    當應用程式處於鎖定狀態時，工具提示與滑鼠懸停效果也會被隱藏，以防止資料透過鎖定遮罩洩漏。
