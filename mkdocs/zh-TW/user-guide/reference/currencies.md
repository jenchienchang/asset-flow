# 幣別與匯率

AssetFlow 支援多種幣別，並請求匯率以顯示換算後的投資組合數值。缺少必要匯率時，相關換算結果會顯示為無法使用。

## 運作方式

- 每項資產可以用自己的幣別追蹤（例如美股用 USD，台股用 TWD）。
- 系統會自動取得每筆快照日期的匯率。
- 所需匯率可用時，換算值會以你選擇的顯示幣別呈現。你可以在**設定**（++cmd+comma++）**> 偏好設定**中變更顯示幣別。
- **資料來源**：匯率從 cdn.jsdelivr.net 取得，提供開放原始碼的匯率資料。

## 支援的幣別

AssetFlow 內建一組常用幣別清單。應用程式載入時會向匯率 API 請求擴充的幣別清單，並將成功取得的結果快取在本機供離線使用。

### 完整幣別清單

成功取得幣別清單後，AssetFlow 會在本機快取[匯率 API](https://cdn.jsdelivr.net/npm/@fawazahmed0/currency-api@latest/v1/currencies.json)提供的可用幣別。這包含了數百種法定貨幣與加密貨幣，遠超上方的內建清單。

你可以在瀏覽器中開啟 [API 端點](https://cdn.jsdelivr.net/npm/@fawazahmed0/currency-api@latest/v1/currencies.json)查看完整的支援幣別代碼清單。

## 自動取得行為

匯率在以下幾種情況下會自動取得：

- **建立或匯入快照時**：應用程式會請求資產、現金流與目標幣別所需的匯率。
- **啟動應用程式或還原備份後**：應用程式會檢查現有快照，並請求缺少或無法涵蓋所需幣別的匯率。
- **幣別變更時**：變更顯示幣別、已記錄的幣別或目標幣別，可能需要新的匯率。

## 無法取得匯率時

如果你處於離線狀態或遇到網路問題：

- 快照詳細檢視中會顯示**重試**按鈕，讓你稍後再試。
- 提供原始幣別金額的畫面仍會顯示這些金額；換算後的總額與依賴匯率的計算結果會標示為無法使用。
- 你仍可離線記錄和查看投資組合資料。取得擴充的幣別清單或缺少的匯率需要網路。

!!! note

    AssetFlow 會將取得的匯率儲存在本機。匯率若符合快照日期與顯示幣別，且涵蓋結果所需的所有幣別，就可以離線重複使用。

## 最低餘額幣別

每個類別最低餘額都保留明確的原始幣別；變更顯示幣別不會改變它。類別資產和最低餘額使用各快照儲存的匯率比較。即使沒有資產使用目標幣別，也可能需要取得該幣別匯率；離線或缺少目標匯率時，目標比較與再平衡會無法使用，但有效的資產統計仍會顯示。
