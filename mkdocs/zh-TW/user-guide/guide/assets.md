# 資產

資產代表你投資組合中的個別投資標的，例如股票、債券、ETF、加密貨幣、現金帳戶，或是任何你想追蹤的項目。每項資產屬於一個類別、關聯一個平台，並有對應的幣別。

## 資產列表

資產檢視的左側列出所有資產。你可以使用工具列上的按鈕切換兩種分組模式：

- **依平台**：將資產依持有的券商或服務分組。
- **依類別**：將資產依投資類別分組。

每一列顯示：

- 資產名稱
- 平台
- 類別
- 最新價值（如果資產的幣別與你的主要幣別不同，會顯示幣別標籤）

在資產上按右鍵可開啟快捷選單。只有當資產在所有快照中都沒有記錄值時，才能選擇**刪除**。

![資產列表](../../assets/images/asset-list.png)

### 隱藏停滯資產

工具列上有一個**隱藏停滯資產**切換按鈕（眼睛劃斜線圖示）。按鈕為啟用狀態時（預設），未出現在最新快照中的資產會被隱藏，方便你聚焦目前的投資組合。再次點擊按鈕可讓已平倉或不再持有的資產重新顯示。你的選擇會在切換檢視與重新開啟應用程式時保留。

!!! note

    「停滯資產」是指在最新快照中沒有任何記錄值的資產，其列在價值欄位上會顯示破折號（—）。

## 資產詳細檢視

選取一項資產，即可在右側查看完整的詳細資訊。

### 屬性

所有屬性都可以直接在詳細檢視中編輯：

- **名稱**：資產的顯示名稱。
- **平台**：從現有平台中選擇，或直接建立新平台。
- **類別**：從現有類別中選擇，或直接建立新類別。
- **幣別**：從支援的幣別清單中選擇。

### 價值歷史

價值歷史區段顯示資產的價值隨時間的變化。

- **時間範圍選擇器**：從**全部**、**1Y**、**3M** 或 **1M** 中選擇，聚焦特定期間。
- **折線圖**：資產價值隨時間變化的視覺化圖表。將游標懸停在任一資料點上，可查看確切的日期與數值。
- **顯示換算值**切換：僅在資產幣別與顯示幣別不同時出現。換算模式只繪製匯率可用的數值；切回原幣別可查看完整的已記錄歷史。
- **缺少匯率**：若所選期間仍有可換算的資料點，缺少匯率的日期會以虛線標記，折線也會在該處中斷。提示會顯示受影響日期的數量，點擊可查看清單。若所選期間沒有可換算值，圖表會顯示無法換算的訊息。
- **價值歷史表格**：列出每筆記錄的日期與市場價值；幣別不同時也會顯示換算值。無法換算時會顯示破折號（—）。雙擊或按右鍵任一列，可編輯該快照的值。

## 刪除資產

資產只有在**所有快照中都沒有記錄值**時才能刪除。如果資產仍有記錄值，刪除按鈕會被停用並顯示說明。

若要完全移除一項資產：

1. 從每一筆包含該資產的快照中移除它（在快照的資產明細中按右鍵，選擇**移除**）。
1. 當資產已無任何快照值後，就可以從資產列表中刪除。

!!! note

    資產通常透過 CSV 匯入或在快照中新增來建立。你不需要單獨建立資產，它們會在你第一次將其加入快照時自動建立。
